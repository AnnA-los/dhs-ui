# UI 设计资料目录

后续所有 UI 设计方案、视觉说明、交互稿、页面截图、验收记录和设计决策，都放在本目录。

设计和开发时请保持系统现有风格：Vue2 + Element UI 管理后台、医疗业务场景、克制清晰的工作台体验。可以借用 `ui-ux-pro-max` skill 做方案推演，但最终实现必须与现有系统一致。

## 与 dhs-core 设计文档的关系

- 前后端同步开发时，`dhs-core` 的设计文档可能会给出 UI 设计图或页面说明。
- `dhs-ui` 侧只生成和维护一份 UI 设计图生成/说明文档，统一放在 `docs/ui`。
- UI 文档必须写明对应的 `dhs-core` 设计文档路径或链接，并在 `dhs-core` 设计文档中回链到本目录对应文档。
- 不要在 `dhs-core` 和 `dhs-ui` 两边各维护一套重复 UI 设计图；如果 core 已经有图，ui 侧文档应作为唯一前端实现说明和验收入口，引用 core 图或说明即可。
